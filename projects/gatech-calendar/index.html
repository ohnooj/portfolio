About GT Calendar

Build a custom Georgia Tech academic calendar and export it as an ICS file.

Use

  • Select events with the preset, year, term, and type filters.
  • Preview the selection in Year or Month view.
  • Choose Export ICS to download a calendar file.

Data

Events are extracted from Georgia Tech Registrar calendar sources:

  • Current academic calendar
  • Future academic calendar
  • Registrar calendar data endpoint

Sync

The generator refreshes current and future events from the Registrar while preserving past events from the existing ICS.
